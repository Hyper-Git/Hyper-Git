## Projects

### ☁️ [Pinnacle](https://github.com/Hyper-Git/pinnacle): Multi-AZ AWS environment in Terraform
Web environment across three Availability Zones: VPC, Application Load Balancer, Auto Scaling, RDS PostgreSQL Multi-AZ, Secrets Manager, CloudWatch alarms into SNS. I ran a CPU stress test to prove the alert chain fired, and documented what breaks if one AZ goes down. Torn down to save cost; it rebuilds from the repo.

### ☸️ [Trades Job Tracker](https://github.com/Hyper-Git/trades-job-tracker-kubernetes): Kubernetes app for trades businesses
Frontend and backend as separate workloads behind one Ingress, on a local cluster. Patched seven high-severity OpenSSL findings flagged by Docker Scout and re-scanned to zero. Tested self-healing by deleting a live pod.

### 💰 [AWS Cost Optimisation Dashboard](https://github.com/Hyper-Git/Cost-Optimization-Dashboard): spend visibility for small businesses
Lambda functions and API Gateway pulling data from Cost Explorer into a browser dashboard, showing daily cost, weekly trends and the top services and regions. My first AWS project.
