## 🚀 Featured Projects

### 🤖 Sell My Stuff — AI-Powered Pricing App
> Hackathon project · Full-stack serverless application

Upload a photo of any item and get an AI-generated product description and price suggestion — instantly.

**Architecture:**
- **Backend:** Python FastAPI → AWS Lambda (via Mangum) → API Gateway → AWS Bedrock (Claude Sonnet)
- **Frontend:** React / Vite / Tailwind CSS → S3 → CloudFront
- **IaC:** Terraform across both frontend and backend
- **CI/CD:** GitHub Actions for automated deployment
